PROFILE

幼少期からずっと猫背で身体が硬く、重度の運動音痴として育つ。
20歳でダンスを始めるが、全く上達しないまま30代になる。

ある時「これはスキルではなく、身体の問題なのでは？」と思ったのをきっかけに身体について学び始める。
身体を変えるにつれ、ダンスだけでなく、冷え性やむくみ、肩凝りなどの不調が改善し、日常の過ごしやすさや心の状態まで変わることを実感。

身体を変えることを提供する側になりたいと思い、整体とピラティスの資格を取得。
施術やピラティス指導をしながら、より良い身体を完成させるため、現在進行形で学び続けている。

MESSAGE

自身の体を変えていく中で感じた「これまでの人生9割損していた。もっと早く知りたかった！」そんな実感が、今のRe:moveにつながっています。

自分自身の身体で試し、学んで、また試して。
その中で感じた変化や気づきを、今度は誰かの身体づくりに活かしていきたい。

「ダンスが上達しない」
「身体が思い通りに動かない」
「身体のことをもっと知りたい」

そんな方に、身体が変わっていく面白さや心地よさを感じてもらえたら嬉しいです。
気になることがあれば、受けるか決める前でもお気軽にご相談ください。

Flow

  1. 予約リクエスト

    公式LINEまたはフォームで予約リクエスト

  2. 日時の決定と事前決済

    公式LINEの方にはLINEで、フォームの方にはメールでご連絡いたします。

    日時決定後、カードによる事前決済でお支払いください。

  3. 事前カウンセリングフォームに回答

    事前カウンセリングフォームをお送りします。

    身体の悩み、ダンスの悩みなど、当日までにご回答ください。

  4. 当日

    お話を伺い、動きを確認→施術→セルフケア・エクササイズ・もう一度同じ動きで変化を確認

    当日の服装

    ダンス上達サポートの場合は普段のレッスン着などの動きやすい格好でお越しいただくか、着替えをお持ちください。

    整体のみの場合は私服のままで施術可能ですが、固いジーンズやスカートでの施術は不可とさせて頂きます。

  5. 今後の通い方のご提案

    お一人お一人の目標に合わせて、通い方をご提案します。

  6. キャンセルポリシー

    以下のキャンセル規定をご確認ください。

    • 予約日の3日前まで 無料
    • 予約時間の24時間前まで 予約金額の50%
    • 予約時間の24時間前以降 予約金額の100%
    • 連絡なしの15分以上遅刻 予約金額の100%(無断キャンセル扱い)

    お客様のご事情で予約時間に遅れる場合は、わかり次第ご連絡ください。
